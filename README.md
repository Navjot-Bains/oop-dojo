# OOP Dojo

LeetCode-style practice for object-oriented programming. Dashboard, Learn tab, and a Practice tab with an in-browser editor and test runner.

## Run
```
npm install
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173).

## Structure
- `index.html` – page shell
- `src/main.js` – problems, tests, concepts, app logic
- `src/style.css` – styles

Add a problem by appending an object to the `P` array in `src/main.js`.

## Push to GitHub
```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<you>/oop-dojo.git
git push -u origin main
```
